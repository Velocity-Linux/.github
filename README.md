# Velocity OS Organization

Welcome to the Velocity OS organization on GitHub.

## What This Repository Provides

This repository contains organization-wide GitHub defaults and community health files for the Velocity OS project. It defines issue templates, pull request templates, reusable GitHub Actions workflows, governance documents, and contributor guidelines used across all Velocity OS repositories.

## Contents

- **Issue Templates**: Structured forms for bugs, features, performance regressions, documentation issues, and security reports.
- **Workflows**: Reusable GitHub Actions for building, testing, Rust projects, packaging, documentation, releases, and labeling.
- **Community Health**: Code of Conduct, Contributing Guide, Governance, Security Policy, Support, and Maintainers documentation.
- **Profile**: Organization homepage content displayed on the Velocity OS GitHub profile.

## Usage

Repository maintainers should not modify files directly in downstream repositories that duplicate these settings. All organization-wide defaults are inherited from this repository.

For questions about contributing or governance, see the [CONTRIBUTING.md](CONTRIBUTING.md) and [GOVERNANCE.md](GOVERNANCE.md) files.
